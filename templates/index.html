Connect Last.fm

Create your own Last.fm API credentials once, save them here, then approve access to your Last.fm account. Your secret and session key are never displayed after saving.

1Create a Last.fm API account
Open last.fm/api/account/create while signed in to Last.fm.
2Fill in the application details
Use YT Music Scrobbler as the application name. For the description, enter Synchronizes my YouTube Music listening history with Last.fm.

Callback URL: https://ytscrobbler.kuberbassi.com/api/lastfm-callback
Application homepage: https://ytscrobbler.kuberbassi.com
3Save the API key and secret
Last.fm will provide an API Key and Shared Secret. Copy both into the Last.fm Credentials section in Accounts, then select Save Last.fm Account. Do not put either value in the Session Key field.
4Authorize your Last.fm account
Select Authorize with Last.fm (or Reauthorize after saving), approve access in the popup, and return to this site. Keep popups enabled for this step.
5Confirm the session was received
The site captures and stores the session key automatically. For security, the actual key is intentionally hidden and never needs to be copied. A green Last.fm authorization successful panel confirms that it was received.
How to Extract YouTube Music Browser Headers
1Open music.youtube.com
Open music.youtube.com in your browser (Chrome, Firefox, Edge, or Brave) and ensure you are logged into your Google account.
2Open Developer Tools
Press F12 or right-click anywhere on the page and select Inspect. Switch to the Network tab.
3Filter POST Requests
In the Network tab search filter box, type browse or player. Click on any song or playlist to generate network traffic.
4Copy Request Headers
Click on one of the browse or player network requests. Go to the Headers tab, scroll down to Request Headers, select all text, copy it, and paste it into the Accounts tab!
